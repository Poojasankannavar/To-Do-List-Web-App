# To-Do List Web App

A responsive, front-end To-Do List application built with HTML5, CSS3, and Vanilla JavaScript.

## Features
- Add tasks using the button or Enter key
- Mark tasks complete and undo completion
- Delete tasks
- View total, pending, and completed task counts
- Persist tasks in browser Local Storage
- Responsive layout for desktop and mobile

## Technologies
- HTML5
- CSS3
- Vanilla JavaScript (ES6)
- Browser Local Storage

## How to Run
1. Extract this ZIP file.
2. Open the extracted `To-Do-List-Web-App` folder in VS Code.
3. Open `index.html` with Live Server, or open the file directly in a browser.

## Project Files
- `index.html` — page structure
- `style.css` — layout and responsive styling
- `script.js` — task operations and Local Storage
